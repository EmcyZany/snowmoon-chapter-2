# Common Visual Prompt

Appended verbatim to the end of **every** image and video prompt in this production:

```
Visual continuity for this Snowmoon Chapter 2 adaptation: cinematic grounded science-fiction, hand-painted environment detail combined with believable human characters, restrained natural acting, soft atmospheric depth, realistic fabric and materials, warm green daylight outdoors and muted green-blue practical lighting indoors, subtle film grain, clear faces and hands, controlled color palette of leaf green, oxidized teal, warm amber and concrete gray. Keep character faces, hairstyles, body proportions and clothing exactly consistent with the provided reference images. No subtitles, no captions, no logos, no watermark, no legible generated text, no extra fingers, no duplicated people, no sudden costume changes. 16:9 widescreen composition.
```

Purpose: one shared block keeps palette, lighting, texture, and the "no generated text / no extra fingers" guardrails identical across all twelve scenes without re-typing them each time.
